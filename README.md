One picture of food that looks delicious: a steaming bowl of ramen —
rich golden broth, wavy noodles, a soft egg, chashu, green onions,
nori, chopsticks, and steam curling up. Warm reds and oranges, glossy
highlights, the bowl as the clear hero filling most of the frame.

## Run

```sh
python3 main.py
```

Pure Python 3.13 standard library only — no network, no randomness,
no external files. Writes a deterministic 1024×1024 PNG to
`/output/entry.png` (byte-identical on every run).
